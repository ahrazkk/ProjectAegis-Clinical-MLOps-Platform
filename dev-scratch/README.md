# Dev Scratch

This folder contains previously root-level utility scripts and one-off text dumps used during local experiments and UI patching.

Structure:
- `scripts/`: ad-hoc Python/CJS/JS/PowerShell helper scripts.
- `dumps/`: temporary text snapshots and extracted snippets.
- `temp/`: temporary JSX view fragments.

These files were moved here to keep the project root clean while preserving the tools.
